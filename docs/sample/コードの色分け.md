# コードの色分け

コードブロックの先頭に言語名を書くと、色分けされます。

## PowerShell

```powershell
# ログを整理する
function Remove-OldLog($Path, $Days = 30) {
  Get-ChildItem $Path -Filter *.log |
    Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-$Days) } |
    Remove-Item -WhatIf
}
```

## シェルスクリプト

```bash
#!/bin/bash
# 引数のファイルを数える
for f in "$@"; do
  echo "${f}: $(wc -l < "$f") 行"
done
```

## Python

```python
def total(prices: list[int], tax: float = 0.1) -> int:
    """税込みの合計を返す"""
    return round(sum(prices) * (1 + tax))
```
