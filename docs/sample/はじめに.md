# Markdown を、読みやすく

README やメモ、議事録などの Markdown を、そのまま読んで、印刷・PDF にできます。これは、画面の見え方を確かめるための、サンプルの文書です。

## 主な機能

- 表、タスクリスト、取り消し線、URL の自動リンク
- コードの色分け（バッチ・PowerShell・シェルを含む約500言語）
- Mermaid の図と、Vega-Lite のグラフ
- 印刷と PDF 保存（ページ範囲、用紙、余白、倍率）

## バッチファイルの例

```bat
@echo off
REM バックアップを作る
set DEST=D:\Backup
if not exist "%DEST%" mkdir "%DEST%"
xcopy /e /y "%~dp0data" "%DEST%"
echo 完了しました
```

## 機能の一覧

| 機能 | ビューア | エディタ |
| --- | :---: | :---: |
| 閲覧・検索 | ○ | ○ |
| 編集 | - | ○ |
| 印刷・PDF 保存 | ○ | ○ |
| ダークモード | ○ | ○ |
