# 数式

TeX の書き方で書くと、数式として組まれます（KaTeX）。ここでは、**書き方** と、**表示される数式** を、並べて載せます。

## 独立した行の数式（`$$`）

**書き方**

````text
$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
````

**表示**

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

## math ブロック

**書き方**

````text
```math
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
```
````

**表示**

```math
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
```

## 文中の数式

**書き方**

````text
質量とエネルギーの関係は $E=mc^2$ です。
````

**表示**

質量とエネルギーの関係は $E=mc^2$ です。

## 金額との区別

金額の `$` は、数式にしません。次の文は、そのまま表示されます。

価格は$100から$200です。
