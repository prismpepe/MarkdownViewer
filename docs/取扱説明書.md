# Markdown ビューア 取扱説明書

Markdown（`.md`）ファイルを読むための、閲覧専用のアプリです。文書を書き換えることはありません。

## 1. はじめに

### 動作環境

- Windows 11
- Microsoft Edge WebView2 ランタイム（Windows 11 には標準で入っています）

### インストール

インストールは不要です。zip を展開してできた `MarkdownViewer.exe` を、好きな場所に置いて起動します。

> 初めて起動したときに「Windows によって PC が保護されました」と表示されることがあります。このアプリには署名がないためです。「詳細情報」→「実行」で起動できます。

## 2. 起動のしかた

### 2.1 ファイルを指定して開く

エクスプローラーで Markdown ファイルを `MarkdownViewer.exe` の上にドラッグ＆ドロップすると、そのファイルが開きます。「3. エクスプローラーから開く」の設定をすると、ファイルのダブルクリックで開けるようになります。

### 2.2 何も指定せずに開く

`MarkdownViewer.exe` をダブルクリックすると、最初に「読みたいファイルのあるフォルダー」を選ぶ画面が出ます。フォルダーを選ぶと、左側にそのフォルダーの Markdown の一覧が表示されます。一覧のファイル名をクリックすると、右側に内容が表示されます。

## 3. エクスプローラーから開く（ダブルクリックで起動）

一度だけ、次の設定をします。

1. `登録.cmd` をダブルクリックします。登録できたことを知らせるメッセージが出ます。管理者権限は要りません。
2. 任意の Markdown ファイルを右クリックし、「プログラムから開く」→「別のプログラムを選択」を選びます。
3. 一覧から「Markdown ビューアで開く」を選び、「常に使う」を押します。

以後、Markdown ファイルをダブルクリックするとこのアプリで開きます。

元に戻すときは、`登録解除.cmd` をダブルクリックします。

### フォルダーを右クリックして開く

`登録.cmd` を実行すると、フォルダーを右クリックしたメニューにも、「Markdown ビューアで開く」が加わります。

- **フォルダーを右クリック** →「Markdown ビューアで開く」で、そのフォルダーの Markdown の一覧が開きます（文書は、一覧から選ぶまで開きません）。
- **フォルダーを開いて、何もない場所を右クリック**しても、同じメニューが出ます（いま開いているフォルダーが対象です）。
- **Windows 11 では、右クリックしてすぐ出る短いメニューには出ません。** 「**その他のオプションを表示**」を押した先の、従来のメニューに出ます。Shift キーを押しながら右クリックすると、はじめから従来のメニューが出ます。
- ドライブそのもの（`F:\` など）を右クリックしたメニューには、出しません。ドライブを開いて、何もない場所を右クリックすると出ますが、ドライブ全体が対象になるため、一覧は上限（10秒、5,000件）までの、途中までの表示になります（「5. 一覧について」を参照）。
- `登録解除.cmd` を実行すると、ファイル用の登録と合わせて、フォルダー用のメニューも消えます。


> `登録.cmd` と `登録解除.cmd` は `MarkdownViewer.exe` と同じフォルダーに置いて使います。exe を別の場所へ移したときは、移したあとにもう一度 `登録.cmd` を実行してください。

## 4. 画面の見かた

画面は、上のツールバー、左の一覧、右の本文の3つの領域でできています。

| 領域 | 場所 | 内容 |
| --- | --- | --- |
| ツールバー | 画面の上端 | ファイルやフォルダーを開く、一覧の表示切替、更新、文書内の検索、印刷・PDF 保存、フォントの設定、表示倍率の操作が並びます |
| 一覧 | 左側 | 現在のフォルダー、ファイル名の絞り込み欄、件数、Markdown ファイルの一覧（サブフォルダーごとの見出し付き）が上から順に並びます |
| 本文 | 右側 | 上端に開いているファイルのパスが出て、その下に文書の内容が表示されます |

ツールバーのボタンと、その働きです（表は画面の左から右への並びと同じ順です）。

| 順 | ボタン | 内容 |
| --- | --- | --- |
| 1 | 📁 フォルダーを開く | 読みたいファイルのあるフォルダーを選びます。サブフォルダーの中の Markdown も一覧に出ます |
| 2 | 📄 ファイルを開く | ファイルを1つ選んで開きます |
| 3 | ☰ 一覧を隠す／表示 | 左の一覧を閉じて、本文を広く使います。閉じたあとは「☰ 一覧を表示」になり、押すと元に戻ります |
| 4 | ↻ 更新 | 一覧と本文を読み直します |
| 5 | 🔍 検索 | 表示している文書の中から文字を探します。使い方は「6. 文書の表示」の中の「文書の中を検索する」を参照してください |
| 6 | 🖨 印刷／PDF | 表示している文書の印刷、または PDF への保存です。使い方は「8. 印刷と PDF 保存」を参照してください |
| 7 | 🔤 フォント | 画面・本文・見出し・コード・図のフォント名と大きさを設定します。使い方は「7. 表示倍率」のあとの「表示フォントの設定」を参照してください |
| 8 | 表示倍率（− 数字の欄 ＋ 100% ↔ 全体表示） | 本文の拡大・縮小です。使い方は「7. 表示倍率」を参照してください |

一覧の上部にある絞り込み欄は、ツールバーではなく左側の一覧の一部です。ファイル名（フォルダー名を含む）の一部を入れると、一覧がその語を含むものだけに絞り込まれます。

ウィンドウを狭くすると、ツールバーのボタンは、区切り線で分けたグループごとに、折り返して並びます（ボタンの文字は折り返しません）。

## 5. 一覧について

- フォルダーを選ぶと、その下にあるサブフォルダーも含めて Markdown ファイルを一覧にします。フォルダーごとに見出し（📁）が付きます。
- 次のフォルダーは一覧に出ません：`.` で始まるフォルダー、`.git`、`node_modules`、`__pycache__`、`.venv`、`venv`。
- 表示するのは最大 5,000 件、読み込みに使うのは最大 10 秒です。どちらかの上限に達すると、そこまでの一覧を表示し、件数の行に赤字で「（途中までです）」と出ます。ドライブ全体のような大きなフォルダーを開いたときに、長く待たされないためです。もっと下のフォルダーを選ぶと、全部を出せます。途中までの一覧は、ウィンドウを前面に戻しても自動では読み直しません（「↻ 更新」で読み直します）。
- 他のアプリでフォルダーを整理したあとにこのウィンドウへ戻ると、一覧は自動で最新になります。
- 「📁 フォルダーを開く」で、いま開いているものとは別のフォルダーを選ぶと、開いていた文書は閉じて、本文は空白の表示に戻ります（一覧は、新しいフォルダーのものになります）。同じフォルダーを選び直したときは、文書は開いたままです。
- 前回開いたフォルダーを覚えています。何も指定せずに起動すると、前回のフォルダーの一覧が開き、前回読んでいたファイルがあれば、それも開きます。「フォルダーを開く」も、そこから始まります。
- ファイル名を指定して起動した（ファイルをドラッグ＆ドロップした、ダブルクリックで開いた）ときは、そのフォルダーとファイルは「前回」として記憶しません。次に何も指定せずに起動すると、その前に使っていたフォルダーが開きます。このときでも、「フォルダーを開く」か「ファイルを開く」で選び直すと、そのあとの使用フォルダーは記憶されます。

## 6. 文書の表示

次のものが表示できます。

- 見出し、段落、箇条書き、番号付きリスト、引用、コード
- 表、取り消し線、チェックボックス付きのリスト
- 画像（文書と同じフォルダーなどにある画像は、相対パスで指定されていれば表示されます）
- 文書に埋め込まれた HTML（表、リスト、`<details>` など）
- Mermaid の図（フローチャート、シーケンス図など）。` ```mermaid ` で書かれたコードブロックが図になります。インターネット接続は要りません。図の記述に誤りがあるときは、その図だけ「図を描けませんでした」と理由を出し、元の記述も表示します。
  - Architecture Diagram（`architecture-beta`）では、標準のアイコン（`cloud`・`database`・`disk`・`internet`・`server`）に加えて、**`logos:` で始まる名前のアイコン**（例: `logos:slack-icon`、`logos:aws-lambda`、`logos:aws-s3`）が使えます。アイコン集（iconify の `logos`、約2,200個）はアプリに同梱されているため、インターネットに接続しなくても表示されます。
  - `logos` 以外のアイコン集（`mdi:` など）は同梱していません。使うと、そのアイコンは「?」の印で表示されます（図全体は描かれます）。
- Vega-Lite のグラフ。` ```vega-lite ` で書かれたコードブロック（中身は JSON）がグラフになります。描画にインターネット接続は要りません。JSON の誤りや spec の誤りがあるときは、そのグラフだけ「グラフを描けませんでした」と理由を出し、元の記述も表示します。グラフは、ダークモードでも白地で表示されます。
  - データは、spec に直接書く（`data.values`）か、`data.url` で指定します。`data.url` では、次のものが使えます。
    - `https://…` の URL（インターネット接続が必要です。相手のサーバーによっては読めないことがあります）
    - 文書と同じフォルダー、またはその下のフォルダーにある、`.csv` `.tsv` `.json` のファイル（相対パスで指定します。20MB まで）
  - 文書のフォルダーの外（`../` で上の階層へ出る指定）、絶対パス（`C:\…` など）、`file:` は、安全のため読み込めません。
  - 書き方の例（文書と同じフォルダーの `data/sales.csv` を使う場合）。

    ```json
    {
      "data": { "url": "data/sales.csv" },
      "mark": "bar",
      "encoding": {
        "x": { "field": "month", "type": "ordinal" },
        "y": { "field": "amount", "type": "quantitative" }
      }
    }
    ```

    この例を実際にグラフにするには、コードブロックの先頭を ` ```vega-lite ` にしてください。

### 日本語の強調記号（`**` `*` `~~`）

日本語の文では、強調の記号が、括弧などの記号に接していても強調になります。

```
加入している**「個人賠償責任保険」（火災保険特約）の優先使用を原則**とする。
```

この書き方は、Markdown の標準の規則（CommonMark）では、記号の前後に空白がないと強調にならず、`**` がそのまま表示されます。GitHub など、標準の規則どおりのところでは、前後に半角スペースを入れる必要があります。このアプリでは、**前後が日本語（かな・漢字・ハングル）であれば、スペースがなくても強調になります**。

- 英数字だけの文は、標準の規則のままです（`word**(x)**word` は強調になりません）。
- コードの中（`` `**…**` ``）は、記号がそのまま表示されます。
- このアプリで強調になる書き方でも、GitHub などでは `**` のまま表示されることがあります。ほかの場所へ持っていく文書では、強調の前後に半角スペースを入れておくと、どこでも強調になります。

### リンク

| リンクの種類 | クリックしたとき |
| --- | --- |
| `https://…` `mailto:…` | 普段使っているブラウザー（メールソフト）で開きます |
| 他の Markdown ファイルへのリンク | このアプリで開きます |
| PDF・Word・Excel・PowerPoint などのファイルへのリンク | そのファイルに関連づけられたアプリで開きます（下の説明を参照） |
| 文書内の見出しへのリンク（`#…`） | その見出しへ移動します |

#### ファイルへのリンクの書き方

次の書き方で、パソコン内のファイルを開けます。

| 書き方 | 例 |
| --- | --- |
| 相対パス（この文書があるフォルダーが基準。`../` で上の階層も指せます） | `[仕様書](docs/spec.pdf)`、`[見積](../shared/見積.xlsx)` |
| ドライブ名から始まるパス | `[資料](file:///C:/work/資料.pdf)`、`[資料](C:/work/資料.pdf)` |

- 開けるのは、次の種類のファイルだけです。
  - PDF（`.pdf`）
  - Word（`.doc` `.docx`）、Excel（`.xls` `.xlsx`）、PowerPoint（`.ppt` `.pptx`）
  - リッチテキスト・OpenDocument（`.rtf` `.odt` `.ods` `.odp`）
  - テキスト・表データ（`.txt` `.csv` `.tsv`）
  - 画像（`.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp`）
- 実行ファイル、スクリプト、ショートカット、マクロ付きの Office ファイル（`.docm` `.xlsm` など）は、安全のため開けません。
- ネットワーク上の共有（`\\サーバー名\…`）へのリンクは開けません。
- ファイルが見つからないときや、開けない種類のときは、画面に理由が出ます。
- パスに日本語や空白が含まれるときは、`[資料](docs/日本語%20資料.pdf)` のように空白を `%20` と書くか、`[資料](<docs/日本語 資料.pdf>)` のように `<` `>` で囲んでください。

### 文書の中を検索する

ツールバーの「🔍 検索」（Ctrl+F）で、表示している文書の中から文字を探せます。本文の上に検索バーが開きます。

- 検索する文字列を入れると、一致した箇所がすべて黄色になり、「3 / 6 件」のように、いま何件目か・全部で何件かが出ます。現在の一致はオレンジ色で示され、画面の中央へ移ります。
- 「▼ 次へ」（Enter、F3）、「▲ 前へ」（Shift+Enter、Shift+F3）で一致を順にたどります。最後まで来ると先頭へ戻り、その旨が出ます。
- 「大文字小文字を区別」を選ぶと、`apple` と `Apple` を別の語として探します。選ばないときは区別しません。
- 「正規表現」を選ぶと、`りんご|リンゴ` や `項目\d` のような正規表現で探せます。書き方に誤りがあるときは「正規表現が正しくありません」と出ます。
- 本文の文字を選んでから Ctrl+F を押すと、選んだ文字が検索欄に入ります。
- 閉じるには「✕」か Esc を押します。ハイライトは消え、文書は元のままです。別のファイルを開くと、新しい文書で探し直します。
- 太字の途中など、書式で文字が分かれていても、つなげて探せます。ただし、段落や表のセルをまたぐ語は一致になりません。
- ハイライトは印刷・PDF には出ません。

制限：Mermaid の図・Vega-Lite のグラフの中の文字は探せません。このアプリは閲覧専用のため、置換はありません。

### 安全のための制限

文書に書かれたスクリプトは動きません。埋め込まれた HTML のうち、`<script>`、`<iframe>`、`<form>` などの危険なもの、`onclick` などの動作の指定、`javascript:` のリンクは取り除いて表示します。そのため、HTML の `style="color:red"` のような色や配置の指定は反映されません（`align` や `border` など、HTML の属性は反映されます）。例外は改ページの指定で、「8. 印刷と PDF 保存」の「改ページ」にある書き方は使えます。

## 7. 表示倍率

横長の表などを全体で見渡せるように、表示倍率を変えられます。

| 操作 | 内容 |
| --- | --- |
| − ／ ＋ | 少しずつ縮小／拡大します |
| 数字の欄 | 倍率（10〜500%）を直接入力して Enter |
| 100% | 等倍に戻します |
| ↔ 全体表示 | 横スクロールが要らない大きさに自動で合わせます |
| Ctrl＋マウスホイール | 縮小／拡大します |

- 本文の幅はウィンドウの幅に合わせて広がります。フル画面にすると、その分だけ広く使えます。
- 「全体表示」にしたまま、ウィンドウの大きさを変えたり別の文書を開いたりすると、自動で合わせ直します。ほかの倍率操作をすると、全体表示は解除されます。
- 列の多い表を全体表示にすると、文字が小さくなります。そのときは「☰ 一覧を隠す」で本文を広げてから、「全体表示」を押してください。

### 表示フォントの設定

ツールバーの「🔤 フォント」で、次の5つの部分について、フォント名と大きさを設定できます。変更はすぐ画面に反映され、次回の起動にも引き継がれます。

| 部分 | 内容 | 既定 |
| --- | --- | --- |
| 画面 | ツールバー、一覧、ボタンなど | Yu Gothic UI、14px |
| 本文 | 文書の文章、表、引用など | Yu Gothic UI、14px |
| 見出し | 文書の見出し。フォント名に加えて、H1〜H4 の大きさを、それぞれ設定できます | 本文と同じ。大きさは本文に対する比率（H1 は 2 倍、H2 は 1.5 倍、H3 は 1.17 倍、H4 は 1 倍） |
| コード | コードブロックと、文中のコード | Consolas、13px |
| 図・グラフ | Mermaid の図、Vega-Lite のグラフの文字（軸・凡例・タイトルなど）。Vega-Lite は、既定の大きさに「設定した大きさ ÷ 16」を掛けます | Trebuchet MS 系、16px |

- フォント名は、各部分につき1つだけ設定します。入力欄を押すと、インストール済みのフォントの一覧が出ます。文字を打つと、一覧が絞り込まれます（`メイ` や `Yu` など）。一覧から選ぶか、名前を直接入力します。
- 何も選ばずに入力欄から離れると、いまの設定のままです。
- 空欄は既定の表示です。各行の「既定」ボタンで、その部分のフォント名と大きさ（見出しは H1〜H4 も）を、まとめて既定に戻せます。「すべて既定に戻す」で5つすべてを戻せます。
- 大きさの欄の「▲▼」（または、欄を選んでの ↑↓ キー）は、空欄のときは既定の大きさを基準に、1px ずつ増減します。
- 見出しの大きさは、H1〜H4 の欄に px で入れます（8〜120px）。空欄の見出しは、既定の比率のままです（H5・H6 は設定できません）。
- 大きさは、画面が 8〜40px、本文・コード・図が 8〜60px です。範囲を超えると、その範囲の端の値になります。
- 「画面」の大きさは、ツールバー・一覧・本文上端のパスの表示を、まとめて拡大・縮小して合わせます。
- 「図・グラフ」を変えると、表示中の文書の図を描き直します（読んでいる位置は保たれます）。
- Vega-Lite の spec に `config`、`fontSize`、`font` を直接書いているグラフは、その指定が優先され、この設定は効きません。
- 本文の大きさは、「7. 表示倍率」の倍率とは別です。倍率は、フォントの大きさに掛かります。
- 印刷・PDF 保存にも、本文・見出し・コード・図のフォントが反映されます。

## 8. 印刷と PDF 保存

ツールバーの「🖨 印刷／PDF」（Ctrl+P）で、表示している文書を、印刷または PDF ファイルにできます。ツールバーや一覧などの画面の部品は出力されず、**本文だけ**が紙面に流れます。文書を開いていないときは、「印刷する文書を開いてください」と出て、ダイアログは開きません。

### ダイアログの項目

| 項目 | 内容 |
| --- | --- |
| 出力先 | 「印刷する」または「PDF ファイルに保存する」。選ぶと、実行ボタンの表示が「印刷する」「PDF を保存…」に変わります |
| ページ | 「すべて」または「指定」。指定の書き方は次の節を参照してください。隣に「全 5 ページ」のように全ページ数が出ます |
| 用紙・向き | A4、A3、B5、B4、Letter と、縦／横 |
| 余白 | 標準、狭い、広い、なし |
| 倍率 | 25〜200%（既定は 100%） |
| 幅の広い表は、用紙に収まるよう縮小する | 既定でオンです。用紙の幅に入らない表があるとき、倍率を自動で下げて収めます（下限は 20%）。オフにすると、指定した倍率のままになります |
| 背景色を印刷する | 表の見出しの色や、コードの背景の色を出力します |
| ヘッダーとフッターを付ける | ヘッダーに日付とファイル名、フッターにファイルの場所とページ番号が入ります |
| プリンター | 印刷のときだけ表示されます。使えるプリンターから選びます（既定のプリンターが選ばれています） |
| 部数・白黒で印刷する | 印刷のときだけ表示されます。部数は 1〜99 |
| 仕上がりを確認（PDF を開く） | いまの設定で作った PDF を、Windows で PDF を開くアプリで開き、仕上がりとページ分けを確認できます。確認用の一時ファイルで、保存はされません |

用紙・向き・余白・倍率を変えると、全ページ数を自動で数え直します（「ページ数を調べています…」と出ます）。

### ページの指定

「指定」を選ぶと、ページ番号を入力できます。

| 入力 | 出力されるページ |
| --- | --- |
| `3` | 3ページ目だけ |
| `1-3` | 1〜3ページ |
| `1-3,5` | 1〜3ページと5ページ |
| `5-` | 5ページ目から最後まで |
| `2,4,6-8` | 2、4、6〜8ページ |

- 全角の数字や、全角のハイフン・読点（`１ー３、５`）でも入力できます。
- 書き方が正しくないとき、または全ページ数を超えているときは、入力欄が赤くなり、理由が表示されます。直すまで実行できません。
- 指定したページだけの PDF や印刷になります。**ページ番号は、文書全体での番号のままです**（たとえば2ページ目だけを出力すると、フッターは「2/6」になります）。
- ページの指定は、次に開いたときには引き継がれず、毎回「すべて」から始まります。前回の指定が残って、気づかずに一部だけを出力することを防ぐためです。

### 印刷するとき

1. 「🖨 印刷／PDF」を押します。
2. 出力先を「印刷する」にして、ページ・用紙・プリンターなどを選びます。
3. 「印刷する」を押します。「印刷を依頼しました」と出れば、プリンターへ送られています。

「Microsoft Print to PDF」など、一部のプリンターは、続けて保存先を聞く画面を出します。その画面を取り消すと、「印刷されませんでした」と出ます。

### PDF に保存するとき

1. 「🖨 印刷／PDF」を押します。
2. 出力先を「PDF ファイルに保存する」にして、ページ・用紙などを選びます。
3. 「PDF を保存…」を押して、保存先とファイル名を選びます（既定のファイル名は、文書の名前に `.pdf` を付けたものです）。「保存しました」と出れば完了です。

### 仕上がりについて

- **暗い配色でも、紙面は明るい配色**で出力されます。Mermaid の図も、ダイアログを開いている間だけ、紙向けの明るい配色で描き直されます（閉じると元の配色に戻ります）。
- 表の行、図、画像、引用が、ページの途中で切れないようにしています。ただし、1ページより長いものは切れます。表の見出し行は、ページをまたぐと次のページにも繰り返されます。
- 長いコードは、折り返して出力されます。
- 画面の表示倍率や、画面の幅は、出力に影響しません。

### 改ページ（ページを区切る）

文書の好きな位置で、印刷・PDF のページを改められます。文書に次のような HTML を書きます。

| 書き方 | 働き |
| --- | --- |
| `<div class="page-break"></div>` | この位置で改ページします（以降は次のページ） |
| `<h2 class="page-break-before">見出し</h2>` | その要素から、次のページに送ります |
| `<p class="page-break-after">段落</p>` | その要素のあとで、改ページします |
| `<div class="page-break-avoid">…</div>` | 中身がページの途中で切れないようにします（1ページより長いものは切れます） |

- 改ページ用の空の `<div>` は、前後に空行を入れて、1行で書いてください。とくに後ろの空行がないと、次の行が HTML の一部として扱われ、太字などの Markdown の書式が効かなくなります。
- `page-break` のかわりに `pagebreak` とも書けます。
- `<div style="page-break-after: always;"></div>` のような、昔からある書き方も使えます。`style` で通るのは改ページの指定（`page-break-before` `page-break-after` `page-break-inside`、`break-before` `break-after` `break-inside`）だけで、色や配置など、ほかの指定は反映されません。
- 改ページの指定は、印刷と PDF のときだけ働きます。画面（本文）には何も表示されず、表示も変わりません。
- 文書の末尾に改ページを置いても、空白のページは増えません。

### 制限

- 両面印刷、給紙トレイ、用紙の種類など、プリンター固有の設定は、このアプリからは指定できません。必要なときは、PDF に保存してから、PDF を開くアプリで印刷してください。
- ヘッダーとフッターの内容（日付、ファイル名、ファイルの場所、ページ番号）は固定で、入れ替えられません。付けるか付けないかだけを選べます。

## 10. 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 起動しない、画面が真っ白 | Microsoft Edge WebView2 ランタイムが入っているか確認してください（Windows 11 では通常入っています） |
| ファイルへのリンク（PDF など）を押しても開かない | 画面の上に理由が出ます。ファイルの場所（相対パスは、この文書があるフォルダーが基準です）、拡張子（開けるのは上の「ファイルへのリンクの書き方」に書いた種類だけです）、ファイル名の空白（`%20` と書くか `<` `>` で囲みます）を確認してください |
| 一覧にファイルが出ない | 拡張子が `.md` `.markdown` `.mdown` `.mkd` のどれかか、`.` で始まるフォルダーや `node_modules` の中ではないかを確認してください |
| 文字化けする | UTF-8 と Shift-JIS（CP932）は自動で判別します。それ以外の文字コードは正しく表示できません |
| 画像が出ない | 相対パスが実際の位置と合っているか確認してください。20MB を超える画像は埋め込めません。インターネット上の画像は、接続がないと表示されません |
| 図が描かれない | 図の記述の誤りは、図の位置に理由が表示されます。記述を直して ↻ 更新を押してください |
| グラフ（Vega-Lite）が描かれない | グラフの位置に理由が表示されます。JSON の書き方（カンマ、引用符、波括弧）と、spec の項目名を確認し、直してから ↻ 更新を押してください |
| グラフのデータが読めない（`data.url`） | 相対パスは、文書と同じフォルダーかその下にある `.csv` `.tsv` `.json` だけ読めます。`../` を含むもの、絶対パス、`file:` は読めません。`https://` の場合は、インターネットへの接続と、相手のサーバーがほかのサイトからの読み込みを許可しているかを確認してください。うまくいかないときは、`data.values` に直接書いてください |
| 構成図（Architecture Diagram）のアイコンが「?」になる | 同梱しているアイコン集は `logos` だけです。`logos:` のあとの名前の綴りが正しいか確認してください（例: `logos:aws-lambda`）。`logos` に無い名前や、`logos` 以外のアイコン集は、「?」で表示されます |
| ダブルクリックで開かない | 「3. エクスプローラーから開く」の設定を済ませたか確認してください。手順 3 の「常に使う」の選択が必要です |
| 登録を取り消したい | `登録解除.cmd` を実行してください |
| 印刷で「プリンターを使えません」と出る | プリンターの電源・接続と、ダイアログで選んだプリンターが正しいかを確認してください |
| ページの指定が赤くなる | `1-3,5` のような書き方になっているか、ダイアログに表示されている全ページ数を超えていないかを確認してください |
| 印刷で表が用紙からはみ出す、文字が小さい | 「幅の広い表は、用紙に収まるよう縮小する」にチェックを入れる、用紙を大きくする、向きを横にする、余白を狭くする、のどれかを試してください |

## 11. 保存される情報

アプリは、次の情報`%APPDATA%\MarkdownViewer\settings.json` に保存し、次の起動で復元します。

- 前回開いたフォルダーと、読んでいたファイルの場所（ファイル名を指定して起動した回は、保存しません。別のフォルダーを選んで文書を閉じたときは、読んでいたファイルの記録は消えます）
- ウィンドウの位置と大きさ、最大化の状態（画面の外に出てしまう位置は使わず、既定の位置で開きます）
- 表示倍率（「全体表示」かどうかも含みます）と、一覧を隠しているかどうか
- 表示フォントの設定
- 印刷・PDF 保存の設定（用紙、余白など。ページの指定は含みません）

文書の内容は保存せず、文書を書き換えることもありません。このアプリを使わなくなったときは、exe と上記のフォルダーを削除すれば、ほかに残るものはありません（`登録.cmd` を実行した場合は、先に `登録解除.cmd` を実行してください）。
