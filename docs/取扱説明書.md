# Markdown ビューア 取扱説明書

Markdown（`.md`）ファイルを読むための、閲覧専用のアプリです。文書を書き換えることはありません。

## 1. はじめに

### 動作環境

- Windows 11
- Microsoft Edge WebView2 ランタイム（Windows 11 には標準で入っています）

### インストール

インストールは不要です。zip を展開してできた `MarkdownViewer.exe` を、好きな場所に置いて起動します。

> 初めて起動したときに「Windows によって PC が保護されました」と表示されることがあります。このアプリには署名がないためです。「詳細情報」→「実行」で起動できます。

## 2. 起動のしかた

### 2.1 ファイルを指定して開く

エクスプローラーで Markdown ファイルを `MarkdownViewer.exe` の上にドラッグ＆ドロップすると、そのファイルが開きます。「3. エクスプローラーから開く」の設定をすると、ファイルのダブルクリックで開けるようになります。

### 2.2 何も指定せずに開く

`MarkdownViewer.exe` をダブルクリックすると、最初に「読みたいファイルのあるフォルダー」を選ぶ画面が出ます。フォルダーを選ぶと、左側にそのフォルダーの Markdown の一覧が表示されます。一覧のファイル名をクリックすると、右側に内容が表示されます。

## 3. エクスプローラーから開く（ダブルクリックで起動）

一度だけ、次の設定をします。

1. `登録.cmd` をダブルクリックします。登録できたことを知らせるメッセージが出ます。管理者権限は要りません。
2. 任意の Markdown ファイルを右クリックし、「プログラムから開く」→「別のプログラムを選択」を選びます。
3. 一覧から「Markdown ビューアで開く」を選び、「常に使う」を押します。

以後、Markdown ファイルをダブルクリックするとこのアプリで開きます。

元に戻すときは、`登録解除.cmd` をダブルクリックします。

> `登録.cmd` と `登録解除.cmd` は `MarkdownViewer.exe` と同じフォルダーに置いて使います。exe を別の場所へ移したときは、移したあとにもう一度 `登録.cmd` を実行してください。

## 4. 画面の見かた

画面は、上のツールバー、左の一覧、右の本文の3つの領域でできています。

| 領域 | 場所 | 内容 |
| --- | --- | --- |
| ツールバー | 画面の上端 | ファイルやフォルダーを開く、一覧の表示切替、更新、印刷・PDF 保存、表示倍率の操作が並びます |
| 一覧 | 左側 | 現在のフォルダー、ファイル名の絞り込み欄、件数、Markdown ファイルの一覧（サブフォルダーごとの見出し付き）が上から順に並びます |
| 本文 | 右側 | 上端に開いているファイルのパスが出て、その下に文書の内容が表示されます |

ツールバーのボタンと、その働きです（表は画面の左から右への並びと同じ順です）。

| 順 | ボタン | 内容 |
| --- | --- | --- |
| 1 | 📁 フォルダーを開く | 読みたいファイルのあるフォルダーを選びます。サブフォルダーの中の Markdown も一覧に出ます |
| 2 | 📄 ファイルを開く | ファイルを1つ選んで開きます |
| 3 | ☰ 一覧を隠す／表示 | 左の一覧を閉じて、本文を広く使います。閉じたあとは「☰ 一覧を表示」になり、押すと元に戻ります |
| 4 | ↻ 更新 | 一覧と本文を読み直します |
| 5 | 🖨 印刷／PDF | 表示している文書の印刷、または PDF への保存です。使い方は「8. 印刷と PDF 保存」を参照してください |
| 6 | 表示倍率（− 数字の欄 ＋ 100% ↔ 全体表示） | 本文の拡大・縮小です。使い方は「7. 表示倍率」を参照してください |

一覧の上部にある絞り込み欄は、ツールバーではなく左側の一覧の一部です。ファイル名（フォルダー名を含む）の一部を入れると、一覧がその語を含むものだけに絞り込まれます。

## 5. 一覧について

- フォルダーを選ぶと、その下にあるサブフォルダーも含めて Markdown ファイルを一覧にします。フォルダーごとに見出し（📁）が付きます。
- 次のフォルダーは一覧に出ません：`.` で始まるフォルダー、`.git`、`node_modules`、`__pycache__`、`.venv`、`venv`。
- 表示するのは最大 5,000 件です。
- 他のアプリでフォルダーを整理したあとにこのウィンドウへ戻ると、一覧は自動で最新になります。
- 前回開いたフォルダーを覚えていて、「フォルダーを開く」はそこから始まります。

## 6. 文書の表示

次のものが表示できます。

- 見出し、段落、箇条書き、番号付きリスト、引用、コード
- 表、取り消し線、チェックボックス付きのリスト
- 画像（文書と同じフォルダーなどにある画像は、相対パスで指定されていれば表示されます）
- 文書に埋め込まれた HTML（表、リスト、`<details>` など）
- Mermaid の図（フローチャート、シーケンス図など）。` ```mermaid ` で書かれたコードブロックが図になります。インターネット接続は要りません。図の記述に誤りがあるときは、その図だけ「図を描けませんでした」と理由を出し、元の記述も表示します。
  - Architecture Diagram（`architecture-beta`）では、標準のアイコン（`cloud`・`database`・`disk`・`internet`・`server`）に加えて、**`logos:` で始まる名前のアイコン**（例: `logos:slack-icon`、`logos:aws-lambda`、`logos:aws-s3`）が使えます。アイコン集（iconify の `logos`、約2,200個）はアプリに同梱されているため、インターネットに接続しなくても表示されます。
  - `logos` 以外のアイコン集（`mdi:` など）は同梱していません。使うと、そのアイコンは「?」の印で表示されます（図全体は描かれます）。

### リンク

| リンクの種類 | クリックしたとき |
| --- | --- |
| `https://…` `mailto:…` | 普段使っているブラウザー（メールソフト）で開きます |
| 他の Markdown ファイルへのリンク | このアプリで開きます |
| 文書内の見出しへのリンク（`#…`） | その見出しへ移動します |

### 安全のための制限

文書に書かれたスクリプトは動きません。埋め込まれた HTML のうち、`<script>`、`<iframe>`、`<form>` などの危険なもの、`onclick` などの動作の指定、`javascript:` のリンクは取り除いて表示します。そのため、HTML の `style="color:red"` のような色や配置の指定は反映されません（`align` や `border` など、HTML の属性は反映されます）。

## 7. 表示倍率

横長の表などを全体で見渡せるように、表示倍率を変えられます。

| 操作 | 内容 |
| --- | --- |
| − ／ ＋ | 少しずつ縮小／拡大します |
| 数字の欄 | 倍率（10〜500%）を直接入力して Enter |
| 100% | 等倍に戻します |
| ↔ 全体表示 | 横スクロールが要らない大きさに自動で合わせます |
| Ctrl＋マウスホイール | 縮小／拡大します |

- 本文の幅はウィンドウの幅に合わせて広がります。フル画面にすると、その分だけ広く使えます。
- 「全体表示」にしたまま、ウィンドウの大きさを変えたり別の文書を開いたりすると、自動で合わせ直します。ほかの倍率操作をすると、全体表示は解除されます。
- 列の多い表を全体表示にすると、文字が小さくなります。そのときは「☰ 一覧を隠す」で本文を広げてから、「全体表示」を押してください。

## 8. 印刷と PDF 保存

ツールバーの「🖨 印刷／PDF」（Ctrl+P）で、表示している文書を、印刷または PDF ファイルにできます。ツールバーや一覧などの画面の部品は出力されず、**本文だけ**が紙面に流れます。文書を開いていないときは、「印刷する文書を開いてください」と出て、ダイアログは開きません。

### ダイアログの項目

| 項目 | 内容 |
| --- | --- |
| 出力先 | 「印刷する」または「PDF ファイルに保存する」。選ぶと、実行ボタンの表示が「印刷する」「PDF を保存…」に変わります |
| ページ | 「すべて」または「指定」。指定の書き方は次の節を参照してください。隣に「全 5 ページ」のように全ページ数が出ます |
| 用紙・向き | A4、A3、B5、B4、Letter と、縦／横 |
| 余白 | 標準、狭い、広い、なし |
| 倍率 | 25〜200%（既定は 100%） |
| 幅の広い表は、用紙に収まるよう縮小する | 既定でオンです。用紙の幅に入らない表があるとき、倍率を自動で下げて収めます（下限は 20%）。オフにすると、指定した倍率のままになります |
| 背景色を印刷する | 表の見出しの色や、コードの背景の色を出力します |
| ヘッダーとフッターを付ける | ヘッダーに日付とファイル名、フッターにファイルの場所とページ番号が入ります |
| プリンター | 印刷のときだけ表示されます。使えるプリンターから選びます（既定のプリンターが選ばれています） |
| 部数・白黒で印刷する | 印刷のときだけ表示されます。部数は 1〜99 |
| 仕上がりを確認（PDF を開く） | いまの設定で作った PDF を、Windows で PDF を開くアプリで開き、仕上がりとページ分けを確認できます。確認用の一時ファイルで、保存はされません |

用紙・向き・余白・倍率を変えると、全ページ数を自動で数え直します（「ページ数を調べています…」と出ます）。

### ページの指定

「指定」を選ぶと、ページ番号を入力できます。

| 入力 | 出力されるページ |
| --- | --- |
| `3` | 3ページ目だけ |
| `1-3` | 1〜3ページ |
| `1-3,5` | 1〜3ページと5ページ |
| `5-` | 5ページ目から最後まで |
| `2,4,6-8` | 2、4、6〜8ページ |

- 全角の数字や、全角のハイフン・読点（`１ー３、５`）でも入力できます。
- 書き方が正しくないとき、または全ページ数を超えているときは、入力欄が赤くなり、理由が表示されます。直すまで実行できません。
- 指定したページだけの PDF や印刷になります。**ページ番号は、文書全体での番号のままです**（たとえば2ページ目だけを出力すると、フッターは「2/6」になります）。
- ページの指定は、次に開いたときには引き継がれず、毎回「すべて」から始まります。前回の指定が残って、気づかずに一部だけを出力することを防ぐためです。

### 印刷するとき

1. 「🖨 印刷／PDF」を押します。
2. 出力先を「印刷する」にして、ページ・用紙・プリンターなどを選びます。
3. 「印刷する」を押します。「印刷を依頼しました」と出れば、プリンターへ送られています。

「Microsoft Print to PDF」など、一部のプリンターは、続けて保存先を聞く画面を出します。その画面を取り消すと、「印刷されませんでした」と出ます。

### PDF に保存するとき

1. 「🖨 印刷／PDF」を押します。
2. 出力先を「PDF ファイルに保存する」にして、ページ・用紙などを選びます。
3. 「PDF を保存…」を押して、保存先とファイル名を選びます（既定のファイル名は、文書の名前に `.pdf` を付けたものです）。「保存しました」と出れば完了です。

### 仕上がりについて

- **暗い配色でも、紙面は明るい配色**で出力されます。Mermaid の図も、ダイアログを開いている間だけ、紙向けの明るい配色で描き直されます（閉じると元の配色に戻ります）。
- 表の行、図、画像、引用が、ページの途中で切れないようにしています。ただし、1ページより長いものは切れます。表の見出し行は、ページをまたぐと次のページにも繰り返されます。
- 長いコードは、折り返して出力されます。
- 画面の表示倍率や、画面の幅は、出力に影響しません。

### 制限

- 両面印刷、給紙トレイ、用紙の種類など、プリンター固有の設定は、このアプリからは指定できません。必要なときは、PDF に保存してから、PDF を開くアプリで印刷してください。
- ヘッダーとフッターの内容（日付、ファイル名、ファイルの場所、ページ番号）は固定で、入れ替えられません。付けるか付けないかだけを選べます。

| キー | 動作 |

| Ctrl + Shift + O | ファイルを開く |

## 10. 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 起動しない、画面が真っ白 | Microsoft Edge WebView2 ランタイムが入っているか確認してください（Windows 11 では通常入っています） |
| 一覧にファイルが出ない | 拡張子が `.md` `.markdown` `.mdown` `.mkd` のどれかか、`.` で始まるフォルダーや `node_modules` の中ではないかを確認してください |
| 文字化けする | UTF-8 と Shift-JIS（CP932）は自動で判別します。それ以外の文字コードは正しく表示できません |
| 画像が出ない | 相対パスが実際の位置と合っているか確認してください。20MB を超える画像は埋め込めません。インターネット上の画像は、接続がないと表示されません |
| 図が描かれない | 図の記述の誤りは、図の位置に理由が表示されます。記述を直して ↻ 更新を押してください |
| 構成図（Architecture Diagram）のアイコンが「?」になる | 同梱しているアイコン集は `logos` だけです。`logos:` のあとの名前の綴りが正しいか確認してください（例: `logos:aws-lambda`）。`logos` に無い名前や、`logos` 以外のアイコン集は、「?」で表示されます |
| ダブルクリックで開かない | 「3. エクスプローラーから開く」の設定を済ませたか確認してください。手順 3 の「常に使う」の選択が必要です |
| 登録を取り消したい | `登録解除.cmd` を実行してください |
| 印刷で「プリンターを使えません」と出る | プリンターの電源・接続と、ダイアログで選んだプリンターが正しいかを確認してください |
| ページの指定が赤くなる | `1-3,5` のような書き方になっているか、ダイアログに表示されている全ページ数を超えていないかを確認してください |
| 印刷で表が用紙からはみ出す、文字が小さい | 「幅の広い表は、用紙に収まるよう縮小する」にチェックを入れる、用紙を大きくする、向きを横にする、余白を狭くする、のどれかを試してください |

## 11. 保存される情報

アプリは、前回開いたフォルダーの場所と、印刷・PDF 保存の設定（用紙、余白など。ページの指定は含みません）を `%APPDATA%\MarkdownViewer\settings.json` に保存します。文書の内容は保存せず、文書を書き換えることもありません。このアプリを使わなくなったときは、exe と上記のフォルダーを削除すれば、ほかに残るものはありません（`登録.cmd` を実行した場合は、先に `登録解除.cmd` を実行してください）。
