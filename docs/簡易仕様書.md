# Markdown ビューア 簡易仕様書

Windows 11 向けの Markdown 閲覧専用アプリ。編集機能は持たない。

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| 名称 | Markdown ビューア（`MarkdownViewer.exe`） |
| 対象 OS | Windows 11（64bit） |
| 形態 | 単体の .exe（インストール不要、約12MB） |
| 実行に必要なもの | Microsoft Edge WebView2 ランタイム（Windows 11 に標準で入っている） |
| 用途 | Markdown ファイルの閲覧。フォルダー内の一覧からの閲覧にも対応 |

## 2. 起動の仕方

| 起動方法 | 動作 |
| --- | --- |
| `MarkdownViewer.exe ファイル.md` | そのファイルを表示。同じフォルダーの Markdown 一覧も左に出す |
| `MarkdownViewer.exe フォルダー` | そのフォルダーの一覧を表示 |
| `MarkdownViewer.exe`（引数なし） | 最初にフォルダー選択ダイアログを開き、選んだフォルダーの一覧を表示 |
| `MarkdownViewer.exe --register` | エクスプローラーの「プログラムから開く」に登録（現在のユーザーのみ） |
| `MarkdownViewer.exe --unregister` | 上記の登録を解除 |

- 対象の拡張子は `.md` `.markdown` `.mdown` `.mkd`。
- エクスプローラーからの起動は、上記の登録を行ったうえで、Windows 側で「常に使う」を選ぶ必要がある（Windows 11 の仕様で、既定のアプリはプログラムから切り替えられない）。

## 3. 機能

### 3.1 画面構成

- 上部ツールバー：フォルダーを開く／ファイルを開く／一覧の表示切替／更新／印刷・PDF／表示倍率。
- 左：現在のフォルダー、ファイル名の絞り込み欄、件数、ファイル一覧（フォルダーごとの見出し付き）。
- 右：本文。タイトル行に開いているファイルのパスを表示。
- ライト／ダークは Windows の設定に追従する。

### 3.2 ファイル一覧

- 選んだフォルダーの **サブフォルダーを含めて** Markdown を一覧にする（最大5,000件）。
- 次のフォルダーは一覧から除く：`.` で始まるフォルダー、`.git`、`node_modules`、`__pycache__`、`.venv`、`venv`。
- ウィンドウを前面に戻したときに、一覧を自動で取り直す（キャッシュは使わない）。
- 前回開いたフォルダーを覚える（`%APPDATA%\MarkdownViewer\settings.json`）。
- フォルダー選択ダイアログの開始位置：開いているフォルダー → 前回のフォルダー → 起動したフォルダー。

### 3.3 Markdown の表示

| 項目 | 対応 |
| --- | --- |
| 記法 | CommonMark、表、取り消し線、タスクリスト、見出しへのリンク |
| 埋め込み HTML | 許可したタグだけ表示（表・リスト・画像・`<details>` など）。後述 |
| 図 | Mermaid（` ```mermaid ` のコードブロック）。フローチャート、シーケンス図など Mermaid 11 の図種 |
| 画像 | 相対パスの画像は文書に埋め込んで表示（20MB まで）。`http(s)` の画像はネットから取得 |
| リンク | `http(s)` / `mailto` は既定のブラウザーで開く。他の Markdown への相対リンクはこのアプリで開く |
| 文字コード | UTF-8（BOM の有無を問わない）。読めなければ CP932（Shift-JIS） |

### 3.4 表示倍率

- 範囲 10〜500%。`−` `＋` ボタン、数値の直接入力、Ctrl+ホイール、Ctrl+`+` / `−` / `0`（等倍）。
- **全体表示**（Ctrl+9）：横スクロールが要らない最大の倍率に自動で合わせる。ウィンドウの大きさを変えたとき、別の文書を開いたとき、図が描かれたあとにも合わせ直す。
- 本文の幅はウィンドウ幅に追従する（固定幅にしない）。

### 3.5 ショートカット

| キー | 動作 |
| --- | --- |
| Ctrl+O | フォルダーを開く |
| Ctrl+Shift+O | ファイルを開く |
| Ctrl+B | 一覧の表示／非表示 |
| Ctrl+P | 印刷・PDF 保存 |
| F5 | 更新（一覧と本文を読み直す） |
| Ctrl+`+` / Ctrl+`-` / Ctrl+0 / Ctrl+9 | 拡大／縮小／等倍／全体表示 |

### 3.6 印刷・PDF 出力

| 項目 | 内容 |
| --- | --- |
| 起動 | ツールバーの「印刷／PDF」、または Ctrl+P。文書を開いていないときは開かない |
| 出力の対象 | 表示している文書。画面の部品は含めず、本文だけを出力する（`@media print` で本文以外を隠す） |
| 出力先 | プリンターへの印刷、または PDF ファイルの保存 |
| ページ範囲 | すべて／指定（`1-3,5`、`5-`、全角も可）。誤りや全ページ数の超過は、理由を表示して実行させない。ページ番号は文書全体での番号のまま |
| 全ページ数 | 設定（用紙・向き・余白・倍率）を変えるたびに、PDF を作って数え直す |
| 用紙・向き・余白 | A4／A3／B5／B4／Letter、縦／横、標準（15mm）／狭い（8mm）／広い（25mm）／なし |
| 倍率 | 25〜200%。「幅の広い表は用紙に収まるよう縮小する」（既定オン）では、用紙の幅に入らないときに倍率を下げる（下限20%） |
| 背景・ヘッダー・フッター | 背景色の有無、ヘッダー（日付・ファイル名）とフッター（ファイルの場所・ページ番号）の有無 |
| 印刷のみの設定 | プリンター、部数（1〜99）、白黒 |
| 仕上がりの確認 | 設定どおりの PDF を一時ファイルに作り、既定の PDF アプリで開く |
| 配色 | ダークモードでも、紙面は明るい配色。Mermaid の図は、ダイアログが開いている間だけ明るい配色で描き直す |
| ページ分け | 表の行・図・画像・引用はページの途中で切らない。表の見出し行は各ページに繰り返す。長いコードは折り返す |
| 保存する設定 | 出力先、用紙、向き、余白、倍率、縮小、背景、ヘッダー・フッター、プリンター、部数、白黒。ページ範囲は保存しない |
| 実装 | Edge WebView2 の印刷機能（`PrintToPdfAsync`・`PrintAsync`）。`printing.py`（出力）、`print.js`（ダイアログ） |

## 4. 安全に関する設計

文書は他人から受け取ったものである場合があるため、スクリプトが動かないようにしている。

- **埋め込み HTML は許可リスト方式**（`sanitize.py`）。許可したタグと属性だけを残す。
  - `<script>` `<style>` `<iframe>` `<form>` `<object>` などは中身ごと除去。
  - `on…=` 形式のイベント属性、`style` 属性、`javascript:` のリンクは除去。
  - 文字入力欄は表示しない（チェックボックスのみ可）。
- **Mermaid は `securityLevel: strict`** で動かす。図の中のスクリプトやクリック動作は無効。
- Mermaid 本体は exe に同梱しており、図の描画にネット接続は要らない。
- 文書を書き換える機能はない（閲覧専用）。

## 5. 構成

| 要素 | 内容 |
| --- | --- |
| 言語・描画 | Python 3.10、pywebview 6（Edge WebView2 で描画） |
| Markdown 変換 | markdown-it-py 4 ＋ mdit-py-plugins（タスクリスト・見出しアンカー） |
| 図 | Mermaid 11.17.2（同梱） |
| ファイル／フォルダー選択 | Windows 標準ダイアログ（`dialogs.py`。画面とは別スレッドから呼んでも固まらないよう Win32 を直接呼ぶ） |
| 印刷・PDF | Edge WebView2 の印刷機能（`printing.py`・`print.js`） |
| パッケージ化 | PyInstaller（`--onefile --windowed`） |

主なファイル：`mdviewer.py`（本体・Python 側 API・エクスプローラー連携）、`ui.html`（画面）、`sanitize.py`（HTML の除去）、`dialogs.py`（ダイアログ）、`printing.py`（印刷・PDF の出力）、`print.js`（印刷ダイアログ）、`vendor/mermaid.min.js`、`build.cmd`（exe の作成）。

## 6. 制限事項

- 閲覧専用。編集、本文内検索はない。
- 埋め込み HTML の `style` 属性による見た目の指定は効かない（`align` `border` など HTML の属性は効く）。
- 数式（KaTeX など）とコードの色分けには対応していない。
- 相対リンクで開けるのは Markdown ファイルのみ。他の種類のファイルは開かない。
- 非常に大きな文書や、図の多い文書での性能は検証していない。
- 署名のない exe のため、初回起動時に Windows の SmartScreen が警告を出すことがある。
- ファイルの関連付け（`--register`）とエクスプローラーからのダブルクリック起動は、開発時に検証していない。
- 印刷では、両面印刷・給紙トレイ・用紙の種類など、プリンター固有の設定は指定できない。
- 印刷・PDF 出力は、自動検証（用紙サイズ、ページ数、ページ範囲、ダイアログの動作）を通しているが、実際の紙への印刷は、仮想プリンター（Microsoft Print to PDF）の受け付けまでしか検証していない。
